# Earth Textures

Download the following files from https://www.solarsystemscope.com/textures/
and place them in this directory:

| File | Resolution | Max size | Description |
|---|---|---|---|
| `earth-day.jpg` | 4K (4096×2048) | 600 KB | Blue Marble day map |
| `earth-specular.jpg` | 2K | 100 KB | Ocean specular highlight |
| `earth-bump.jpg` | 2K | 100 KB | Elevation bump map |

Until textures are downloaded the globe will render as a white/grey sphere.
